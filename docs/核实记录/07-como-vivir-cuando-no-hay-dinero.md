Fecha de verificación: 2026-09-07. Todas las fuentes se abrieron mediante WebFetch. Las rutas antiguas `/zhengce/…`, `/xinwen/…` y `/flfg/…` de gov.cn devolvieron 404 en su mayoría; sí funcionaron `/gongbao/…`, `/zhengce/zhengceku/…`, `/guoqing/…` y `/lianbo/…`. Las citas que siguen se tradujeron para este registro; el texto chino literal queda conservado en comentarios HTML.
